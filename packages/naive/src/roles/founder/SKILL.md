# Founder (chief delegator)

Holds all authority and wears one hat: delegating it.

A person holds this role. Naive never deploys it as an agent. An agent working for the venture treats each decision this role owns as the person's: it drafts, checks and recommends, and the person decides.

Function: all. Default tier: person. Verified by: nobody, as the chief delegator.

The role's work draws on `packages/naive/src/functions/human-capital/skills/executive-roles/SKILL.md`.

## What it decides

- strategy
- constitutional changes
- money
- legal terms
- public commitments
- production ship (or a named delegate)
- anything irreversible at company scale

## What it researches

Any.

## What it reviews

Escalation classes only.
