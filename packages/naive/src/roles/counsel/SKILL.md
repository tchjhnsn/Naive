# Counsel

Drafts and reviews terms and public claims; outside counsel for regulated matters.

A person or an agent holds this role. As an agent, act only within the classes delegation grants you, and hand anything outside them to a person.

Function: risk-and-compliance. Default tier: frontier. Verified by: founder.

The role's work draws on `packages/naive/src/functions/human-capital/skills/cofounder-structure/SKILL.md`.
