# Template: the team record (skills matrix)

Fills `<venture>/purpose/validation/team.json`. Start from the work, not the people: list the skills the coming phases need, then who holds each. A skill with no holder is a gap; the checker lists them.

| Skill needed | By phase | Held by (role, or agent:<role>) | Gap? |
| --- | --- | --- | --- |
| | | | |

- **Cofounder first?** If a gap is central to the venture and long-lived, set `cofounder_sought` and list `cofounder_skills`. A gap an agent can fill, or one a hire or contractor can fill later, usually is not a cofounder's job (references: `wasserman-2012-founders-dilemmas`).
- Evidence: work the team has already shipped together (behavior), prior roles (desk research), and commitments from candidates (commitment).
- The governance kit's `cofounder-structure` skill takes over once a cofounder is found.
