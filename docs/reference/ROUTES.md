# Routes

One route table serves three interfaces: the CLI (`interface/cli/mentura.mjs`), the MCP server (`interface/mcp/server.mjs`) and the HTTP API (`interface/api/server.mjs`). All three call `interface/router.mjs`, so they cannot disagree. Install them into an agent harness with `interface/skills/install-mentura/SKILL.md`.

Routes follow the Next.js App Router (EE-032). The path is the route: a record in a layer's own kit is `<layer>/<record>`, and a record in a nested kit is `<layer>/<kit>/<record>`, so a route is its record's folder path. The venture comes first: an id, or a nested venture's folder path (`studio/print`), given as `--venture`, a tool argument, or `/ventures/<venture>/` in the API.

| Next.js | Here |
| --- | --- |
| `route` (API endpoint) | record actions read, write, check and template; command routes run |
| `page` | the view action: a Markdown page for a person |
| `layout` | the layout action: system, layer and kit context, skills, references, gate and need-now status |
| `not-found`, `loading`, `error` | a missing record answers with its template and need-now status; a waiting draft is reported on read; a failed check or write answers with the kit's skills and template |
| `[id]` | collection items: `purpose/product/[id]` beside the list route `purpose/product` |
| `[...slug]` | the venture: `studio/print` |
| `(group)` | route groups by phase, below |
| `@slot` | `system/overview`: slots that render side by side, one failing without stopping the rest |
| `_private` | `_drafts/`, never routed |
| `proxy` | gates before every write: schema, decision class (from the data model, applied from the venture's decision rights), the role's routes |
| `robots` | team-plan roles may list the routes they read and write; `system/robots` shows them |
| redirects | `interface/route-aliases.json`: a renamed route keeps its old one as an alias |

Nothing here is written by hand: add a record type to `schema/data-model.json` and a kit, and its route appears. Regenerate the table with `node interface/router.mjs --md`.
