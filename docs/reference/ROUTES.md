# Routes

One route table serves three interfaces: the CLI (`interface/cli/mentura.mjs`), the MCP server (`interface/mcp/server.mjs`) and the HTTP API (`interface/api/server.mjs`). All three call `interface/router.mjs`, so they cannot disagree. Install them into an agent harness with `interface/skills/install-mentura/SKILL.md`.

As in the Next.js App Router, the path is the route: a record in a layer's own kit is `<layer>/<record>`, and a record in a nested kit is `<layer>/<kit>/<record>`. The venture is the dynamic segment, given as `--venture`, a tool argument, or `/ventures/<id>/` in the API. Actions are the handlers, and gates run before a write as middleware does.

Nothing here is written by hand: add a record type to `schema/data-model.json` and a kit, and its route appears. Regenerate the table with `node interface/router.mjs --md`.
