# Lean software development

Principles carried over from lean manufacturing: eliminate waste, optimise the whole value stream from idea to released change, deliver fast, and learn by amplifying feedback. It does not prescribe roles or events, so it is usually used to judge and improve another method rather than to replace one.

See [[kanban]] for a flow practice that applies these ideas directly.
