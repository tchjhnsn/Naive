# Assignment register

Each file here records which methodologies were chosen for one system, and why. Entries are named `A-NNN-<slug>.md` and are written by `node skills/methodology-selection/ee.mjs propose`; a person ratifies them. System descriptions go in `register/_systems/`, and every `ee recommend` run is saved under `register/_recommendations/`. `register/INDEX.md` is generated by `ee index`; do not edit it by hand.

This copy of the register is empty. Assignments describe real projects, so they live with those projects rather than in the shared methodology. For a worked example, see `skills/methodology-selection/fixtures/valid/register/`.
