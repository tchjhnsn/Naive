# Per-Entity Orchestration HTML Template — Companion Note

> The readable artifact is **[[per-entity-orchestration-template.html]]**. Open it in a browser. This MD note exists for Obsidian discoverability.

## What this is

The methodology-level template that every project (or sub-entity per §36 recursion) instantiates as its own orchestration HTML. The template has `{{TOKEN}}` placeholders for entity-specific values. First instance authored at a project note.

## Ten sections in the template

1. Entity header (class, lifecycle, ambition tier, recursion relations)
2. Lane status (Articulate / Build / Ship / Operate swim-lane with current position)
3. Three pillars (Product / Brand / Business cards with leads, status, products)
4. Deliverables inventory (Tier 1 / Tier 2 / Tier 3)
5. Methodology mechanisms (active skills + commands + hook status)
6. Decisions + idea archive
7. Canonical documents + cross-references
8. Roles + open positions
9. Sub-entities (recursive per §36)
10. Structured state JSON (for future software port per §39)

## Per §39 orchestration trajectory

This HTML template is the current-state surface for solo-operator + AI use. The embedded `<script type="application/json" id="entity-state">` block is the schema a future multi-user software port reads from. The HTML and JSON stay in sync.
