# UX_UNIVERSAL_KNOWLEDGE_AND_ASSETS

## Working definition

UX is the design of conditions under which users form correct expectations,
take intentional actions, and receive legible outcomes with minimal ambiguity.

## Universal knowledge set

1. Jobs/outcomes vs features
2. Mental models and expectation transfer
3. IA: objects, routes, and discoverability
4. Affordances/signifiers/feedback loops
5. State behavior (empty/loading/error/partial/success/permission)
6. Trust and promise-keeping
7. Accessibility and inclusion
8. Evaluation criteria (task success, error recovery, time-to-value)

## Universal UX asset types

- Research assets: problem statements, user interviews, competitor analyses
- IA assets: object model, route map, taxonomy
- Interaction assets: flows, state tables, behavioral contracts
- Presentation assets: hierarchy systems, content contracts, motion roles
- Trust assets: disclosure patterns, failure semantics, provenance notices
- Evaluation assets: acceptance checks, usability protocols, regressions

## Non-assets

Mission statements, backend schema internals, and brand mythology are inputs to
UX work, not UX assets by themselves.
