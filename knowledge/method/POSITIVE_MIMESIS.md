# POSITIVE_MIMESIS

## Definitions

- **Mimesis:** model-mediated learning/desire/practice.
- **Mimetic rivalry:** convergence on similar status/object through shared models.
- **Negative mimesis:** rivalry that attempts to seize the model's identity,
  synonym, symbolic position, or core object under rebranding.
- **Positive mimesis:** rivalry that names the model, copies proven function
  discipline, and differentiates on object/completeness without identity theft.

## Rebranding rule

Rebranding is a form of negative mimesis **when** it appropriates model
identity/object while claiming novelty. Reuse of interaction shape alone is not
negative if object boundary and ontology remain distinct and explicit.

## Relationship to research phases

- Mimetic phase: identify what is worth inheriting from the model.
- Anti-mimetic phase: identify where the model's ontology fails for our object.
- Synthesised phase: produce the strategy contract (adopt/reject/transform/open).

## Pass/fail checks

| Check | Positive pass | Negative fail |
|---|---|---|
| Model naming | model explicitly credited | lineage erased |
| Function inheritance | copy discipline/procedure | copy only cosmetics/chrome |
| Object boundary | object clearly distinct | model object seized under new label |
| Completeness claim | honest for our object | borrowed false universality |
| Trust mechanism | earned through delivered outcomes | slogan-level equivalence claim |
