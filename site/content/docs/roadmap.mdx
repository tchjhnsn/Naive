What we are building, in order. No dates. Each item moves to the [changelog](/docs/changelog) when it ships.

## Now

- Every record write through the router. Some older modules still write files directly. A check stops any new ones, and each old one moves behind the router in turn.
- Docs rewritten from the code. Many of these pages describe an older layout.
- Old template files removed from the package.

## Next

- Naive's own roles run as digital workers on Naive's own records, with a staffing gate for Naive. The six roles exist as records under `agents/`: product manager, architect, requirements engineer, release manager, technical writer and instruction steward. `naive role check` and `naive graph --role` do not read them yet.
- Signed identity. Today a person or an agent is who the environment says it is.
- The gate on merged records after a sync.
- A place to host a shared store, so two people can work on one business.

## Later

- Businesses simulated end to end, to test every function and phase.
- Launch readiness and a roadmap by date inside feature reports.
- Capability levels 4 and 5, which need a measure bound to each element.
