The MCP server is `packages/naive/src/interfaces/mcp/server.ts`. It speaks MCP over stdio and has no dependencies. The tool and resource list is the [MCP reference](../reference/mcp).

## Add it to Cursor

Put this in `.cursor/mcp.json`, with your own paths:

```json title=".cursor/mcp.json"
{
  "mcpServers": {
    "mentura": {
      "command": "node",
      "args": ["/path/to/naive/packages/naive/src/interfaces/mcp/server.ts"],
      "env": { "MENTURA_WORKSPACE": "/path/to/ventures", "MENTURA_HARNESS": "Cursor" }
    }
  }
}
```

## Ask for the overview

Ask the agent to call `mentura_ventures`, then `mentura_view` with route `system/overview`. Every write through the server counts as an agent's.
