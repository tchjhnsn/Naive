<Section title="What's in Naive?" wide>
  <Features>
    <Feature title="Records">Your venture is a folder of plain JSON and Markdown. You own it, and every agent reads the same thing.</Feature>
    <Feature title="Decisions">See which decision needs you first. Agents propose, and you decide.</Feature>
    <Feature title="The gate">You decide which writes an agent may make without you. Every write passes the gate first.</Feature>
    <Feature title="Venture structure">Marketing, product, finance and the rest, each declared once in venture.json.</Feature>
    <Feature title="Decision library">Frames turn a problem in your own words into the decisions hidden inside it.</Feature>
    <Feature title="Agents and people">Code by default, a model where a judgment is needed, and every answer marked with whose it is.</Feature>
    <Feature title="Provenance">Who wrote each record, from what, and under which decision.</Feature>
    <Feature title="Time travel">Read any record exactly as it was at any moment. Every version is kept, named by its own hash.</Feature>
    <Feature title="What's built" highlight>See what runs today, and what is still design.</Feature>
  </Features>
